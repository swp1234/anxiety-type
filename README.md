# Anxiety Type

Eight-scenario, author-created worry-response reflection at `/anxiety-type/`. It is not a diagnostic or validated assessment.

## Release contract

- Ads remain fully suspended while the 2026-09-03 invalid-traffic restriction is active.
- Public funnel: `anxiety_type_view` → `start` → `progress` (four accepted answers) → `complete`, with success-only `share`, `next_click`, and delegated `related_click`.
- Events contain only `event_category`; answers, result labels, scores, locale, URL, and timing stay private.
- Result method is transparent: one point per response choice; first matching label breaks ties.
- Verify from the workspace root with `npm run verify:anxiety-type`.
